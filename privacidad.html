Finalidades primarias

  • Procesar información mediante OCR
  • Generar recordatorios y alertas
  • Generar resúmenes financieros
Finalidades secundarias
  • Mejorar el servicio
  • Analítica
  • Comunicación con el usuario

04 Uso de tecnologías (OCR y automatización)

Doclyfi utiliza tecnologías de reconocimiento óptico de caracteres (OCR) y procesamiento automatizado.

Estos procesos pueden tener errores y generar estimaciones. No reemplazan la revisión manual del usuario.

05 Acceso a la información

Doclyfi declara que:

  • No accede manualmente a los documentos.
  • No analiza contenido de forma humana.
  • El procesamiento es completamente automatizado.

06 Transferencia de datos

Doclyfi podrá compartir datos con proveedores tecnológicos, servicios de nube y plataformas como WhatsApp, siempre bajo medidas de seguridad.

Los datos personales no serán vendidos bajo ninguna circunstancia.

07 Seguridad

Doclyfi implementa medidas técnicas razonables para proteger tu información:

  • Cifrado de datos
  • Controles de acceso
  • Medidas técnicas razonables de protección

09 Uso de WhatsApp

Al usar WhatsApp como canal de comunicación con Doclyfi, el usuario acepta las políticas de dicha plataforma. Doclyfi no controla ni es responsable de la infraestructura de WhatsApp.

10 Conservación de datos

Los datos personales se conservarán mientras:

  • Exista una relación activa con el usuario.
  • Sea necesario para la prestación del servicio.

11 Cambios al aviso

Doclyfi puede modificar este aviso de privacidad en cualquier momento. Se recomienda al usuario revisar periódicamente este documento para estar al tanto de cualquier actualización.

12 Consentimiento

Al usar Doclyfi, el usuario acepta los términos descritos en este aviso de privacidad.
